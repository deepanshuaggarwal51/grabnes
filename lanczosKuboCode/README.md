### How do I get set up? ###

* Summary of set up: path/to/executable/grabnes < Gendata.in > job.out. A manual is available with the most common input variables. Work in progress.
* Configuration: clone the complete folder to your local machine. Compile using make clean followed by make. Makefiles are available for TACC clusters and a few local clusters.
* Dependencies: none that is required.
* How to run tests: none at the moment. 
* Deployment instructions: none at the moment.
